# 군위수서 주중이용권 리플렛 미리보기

`index.html` 을 브라우저로 열면 3단접지(말아접기) 접힘 순서대로 볼 수 있다.

- `fold/{버전}/` : 인쇄용 PDF에서 도련을 뺀 재단 영역만 면별로 자른 150dpi 이미지
- 파일명은 접힘 번호 기준
  - 표지면 `o5`(97mm 접힘면) · `o6`(뒷면) · `o1`(표지)
  - 안쪽면 `i2` · `i3` · `i4`(97mm 접힘면)

## 버전 추가 방법

1. 인쇄용 PDF를 새로 뽑는다
2. `_build/slice_fold.py` 의 `VERSION` 을 바꿔 실행하면 `fold/{버전}/` 이 생긴다
3. `index.html` 의 `VERS` 배열에 `['v2', 'v2 설명']` 형태로 한 줄 추가한다

실측 규격은 재단 297 x 210mm, 작업 301 x 214mm, 도련 사방 2mm.
